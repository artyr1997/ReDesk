# Security policy

## Supported versions

Only the latest release of re: desk is supported: the one in ReSpace.dmg at [getrespace.app](https://getrespace.app), built from the `main` branch here. Fixes go into the next release; there are no backports.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Report it privately instead:

- on GitHub, through **[Report a vulnerability](https://github.com/artyr1997/ReDesk/security/advisories/new)** (this repository's Security tab).

Say what you found, how to reproduce it, and which macOS and app version you used. You'll get an answer within a week. Once a fix is out, the advisory is published, crediting you if you like.

## What this app does with your data

No accounts, no analytics, nothing sent to the developer. What re: desk does online, and why, is in the [privacy policy](https://getrespace.app/privacy).
